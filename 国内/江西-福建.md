# 江西 · 福建 12 日游（自然风光为主）

> **路线概览**：南昌 → 上饶 / 三清山 → 武夷山 → 福州 → 泉州 → 南靖土楼 → 厦门  
> **主题**：花岗岩峰林、丹霞与竹筏、海岸与土楼田园；博物馆与古城穿插  
> **建议季节**：4–6 月、9–11 月（避开暑期酷热与台风高发期）  
> **交通主轴**：高铁串联城市，景区内换乘景区大巴 / 观光车  
> **压缩原则**：三清山集中走南清园+西海岸一天；福州以省博为主不拉长；厦门收在 1.5–2 天

## 详细日程

### Day 1｜南昌（文化开场）

**住宿**：南昌市区（八一广场 / 滕王阁一带，地铁便利）

| 时段 | 安排 |
|------|------|
| 上午 | 抵达南昌，入住休整 |
| 下午 | **滕王阁**（登阁看赣江；提前网上预约） |
| 傍晚 | **江西省博物馆**（注意闭馆时间，周一常休馆） |
| 晚上 | 万寿宫 / 绳金塔散步；南昌拌粉、瓦罐汤 |

---

### Day 2｜南昌 → 上饶 → 三清山脚下

| 时段 | 安排 |
|------|------|
| 上午 | 高铁 **南昌东 / 南昌 → 上饶**（约 1–1.5 小时） |
| 下午 | 景区直通车或包车前往 **三清山**（约 1–1.5 小时） |
| 傍晚 | 入住 **汾水 / 金沙** 山脚；买好次日门票 + 往返索道 |

**提示**：12 日版三清只留 1 个完整登山日，务必住山脚，第二天早上海拔凉爽、云海概率更高。

---

### Day 3｜三清山（南清园 · 西海岸）— 江西段高光

> 世界自然遗产；本趟把精华压进一天走完。

**经典环线（推荐）**：  
**金沙索道上山 → 南清园 → 西海岸 → 阳光海岸 → 汾水索道下山**

必看：
- **南清园**：司春女神、巨蟒出山、东方女神
- **西海岸峰林栈道**：悬崖步道与云海，风光最疏朗
- 体力好可加 **玉台** 观景

**住宿**：山脚（次日早下山转场）  
**装备**：防滑鞋、冲锋衣、防晒；山顶温差大，抓绒或薄羽绒随身。

> 节奏：早上索道一开就上山，中午前走完南清园，下午专留给西海岸，避免赶场。

---

### Day 4｜三清山 → 武夷山（转场日）

| 时段 | 安排 |
|------|------|
| 上午 | 下山，返回上饶方向高铁站 |
| 中午–下午 | 上饶 → **武夷山北**（或南平市再转）；也可山脚包车直达武夷（约 2.5–3.5 小时） |
| 傍晚 | 入住 **武夷山度假区**；可选 **大红袍景区** 外围轻走，或休息 |

**住宿**：度假区核心（近九曲溪、演出场）

---

### Day 5｜武夷山（山景主日）

全日登山，建议顺序：

1. **天游峰**（俯瞰九曲溪，武夷第一观景点）
2. **一线天 / 虎啸岩**（丹霞夹缝、岩壁质感）
3. 有余力：**鹰嘴岩** 一带茶园与丹霞过渡带

**提示**：确认门票是一日还是多日、观光车覆盖范围；山路台阶多，留体力给次日竹筏即可，不必再加高强度线。

---

### Day 6｜武夷山（竹筏 + 演出）— 本趟高光之一

| 时段 | 安排 |
|------|------|
| 上午或下午 | **九曲溪竹筏**（务必提前预约；前排视野更好，防晒帽必备） |
| 傍晚 | 茶馆小憩、休整 |
| 晚上 | **《印象大红袍》** 实景演出（中场座位性价比通常最好） |

竹筏约 1.5–2 小时，大王峰、玉女峰等近距离掠过，是「人在画中游」的一天。

---

### Day 7｜武夷山 → 福州（省博日）

| 时段 | 安排 |
|------|------|
| 上午 | 退房；高铁 **武夷山北 / 南平 → 福州 / 福州南**（约 1.5–2.5 小时） |
| 下午 | **福建省博物馆**（自然与历史展可按兴趣选看；注意周一闭馆） |
| 傍晚 | 西湖公园 / 左海一带散步，或三坊七巷外围夜色 |
| 晚上 | 鱼丸、肉燕、荔枝肉等福州小吃

**住宿**：省博 / 西湖或东街口一带，次日去车站方便。

> 12 日版福州不安排鼓山整日徒步；若火车较晚、仍想爬山，可把省博压缩为 2 小时，改去鼓山半日。

---

### Day 8｜福州 → 泉州（清源山 + 古城）

| 时段 | 安排 |
|------|------|
| 上午 | 高铁福州 → 泉州（约 1 小时） |
| 下午 | **清源山**（老君岩、弥陀岩一线；山路不陡，自然+石刻兼顾） |
| 晚上 | 西街、开元寺外围；面线糊、海鲜粥 |

**住宿**：泉州古城或清源山南门附近。

---

### Day 9｜泉州 → 南靖土楼（山谷田园）

| 时段 | 安排 |
|------|------|
| 上午 | 包车直达最省事；或高铁至南靖 / 龙山 + 景区专线 |
| 下午–傍晚 | **田螺坑**「四菜一汤」远眺 + **云水谣** 古道（古榕、溪流、竹林，自然感强） |
| 晚上 | 住土楼民俗客栈（云水谣 / 塔下 / 田螺坑附近） |

**自然向建议**：少钻楼内打卡，多走溪畔与观景台；黄昏光线最佳。

---

### Day 10｜南靖 → 厦门

| 时段 | 安排 |
|------|------|
| 上午 | 补走未完成土楼线（田螺坑 ↔ 云水谣择一深化） |
| 中午 | 包车约 2–2.5 小时赴厦，或回站转高铁 |
| 下午 | 入住厦门岛内 |
| 傍晚 | **环岛路** 骑行 / 电动车看海（曾厝垵→胡里山一段经典） |
| 晚上 | 曾厝垵或沙坡尾觅食 |

**住宿**：曾厝垵 / 厦大周边 / 中山路。

---

### Day 11｜厦门（海岛自然日）

任选主轴（建议只深做一个，避免两边都赶）：

**方案 A · 海岸优先**  
环岛路分段骑行、白城 / 珍珠湾沙滩、山海健康步道或五缘湾湿地；日落留在环岛路西段。

**方案 B · 鼓浪屿优先**  
早船上岛：日光岩远眺海天、菽庄花园听涛；少钻商业街，多走岛上步道。

备选半天：**万石植物园**（植被与山岩，适合不想上岛时）。

晚上：海鲜收尾（先问价）。

---

### Day 12｜厦门收尾 · 返程

| 时段 | 安排 |
|------|------|
| 上午 | 厦大外围 / 沙坡尾轻松逛；若航班晚可再补环岛路一段 |
| 视时刻 | **厦门高崎机场** 或 **厦门站 / 厦门北** 返程 |

## 交通速查

| 路段 | 推荐方式 | 大致耗时 |
|------|----------|----------|
| 南昌 → 上饶 | 高铁 | 1–1.5 h |
| 上饶 ↔ 三清山 | 景区巴士 / 包车 | 1–1.5 h |
| 三清山 / 上饶 → 武夷山 | 高铁 + 出租 / 包车 | 2.5–4 h |
| 武夷山 → 福州 | 高铁 | 1.5–2.5 h |
| 福州 → 泉州 | 高铁 | ~1 h |
| 泉州 → 南靖土楼 | 包车（推荐）或高铁+专线 | 2–3 h |
| 南靖 → 厦门 | 包车或高铁 | 2–2.5 h |

**进出港**：南昌进、厦门出（单程机票 + 沿途高铁最顺）。

## 与 15 日版相比砍掉了什么

| 压缩点 | 处理方式 |
|--------|----------|
| 三清山第 2 天（东海—三清宫） | 改为 1 天专攻南清园 + 西海岸 |
| 福州鼓山整日 | 改为省博为主；可选半日鼓山替换 |
| 厦门第 3 天 | 合并为 1 个完整游玩日 + 半天返程 |
| 武夷「热身日」 | 并入转场傍晚，不单列 |

若体力强、想再野一点：D7 省博改鼓山，或 D11 海岸 + 植物园拼一天（会较累）。
