# 江西 · 福建 12 日游（自然风光主题 · 详版）

> **主线**：南昌 → 上饶 / 三清山 → 武夷山 → 福州 → 泉州 → 南靖土楼 → 厦门  
> **自然主轴**：三清山花岗岩峰林 → 武夷山丹霞 + 九曲溪 → 清源山 → 土楼山谷梯田 → 厦门海岸  
> **出发地**：深圳。**深圳 → 南昌进，厦门 → 深圳出**，全程单向不走回头路  
> **最佳季节**：4–6 月（三清山高山杜鹃、雨后云海）与 9–11 月（天高气爽、闽南最舒适）；7–8 月闽南酷热且台风多，1–2 月山区湿冷  
> **强度**：中等偏上。D3 三清山是唯一的「大腿日」，约 15–20 公里步行、大量台阶；D5 武夷山已按需求减去虎啸岩，强度降为中等

## Day 1｜深圳 → 南昌：赣江边的开场

### 深圳到南昌怎么走

| 方式 | 路线 | 耗时 | 建议 |
|------|------|------|------|
| **高铁（推荐）** | 深圳北 → 南昌西（赣深 + 昌赣高铁贯通） | 约 4.5–5.5 小时 | 选 **07:00–08:00 的早班车**，中午前后到南昌西，下午行程不受影响；票价二等座约 ¥450–500 |
| **飞机** | 深圳宝安 T3 → 南昌昌北 | 飞行约 1.5 小时，含两头往返约 4 小时 | 时间上并不比高铁省多少，除非买到便宜早班机 |

**到市区**：南昌西站坐地铁 2 号线直达市区（约 30 分钟）；昌北机场坐机场大巴或打车约 40–50 分钟。

### 当日安排

| 时间 | 安排 | 说明 |
|------|------|------|
| 07:30 | 深圳北出发 | 建议提前一晚订好票并选靠窗，赣南段山景不错 |
| 12:30–13:30 | 抵达南昌西、入住、午餐 | 建议住 **八一广场 / 滕王阁** 一带，地铁 1、2 号线交汇 |
| 14:30–16:30 | **江西省博物馆** | 新馆在红谷滩，需**提前网上预约**；重点看海昏侯墓出土的金器与青铜器（展陈以现场为准） |
| 17:00–19:00 | **滕王阁** | 傍晚登阁，正对赣江西沉的落日，是全天光线最好的一小时 |
| 19:30 起 | 万寿宫历史街区 / 绳金塔 | 拌粉、瓦罐汤、藜蒿炒腊肉 |

**时间紧的备用排法**：若买不到早班高铁、下午才到，就把博物馆挪到 D2 上午（南昌西站发车前塞进 2 小时），D1 只留滕王阁看落日。  
**最佳游览时间**：滕王阁 17:00 后人流回落且逆光转顺光；若当晚有《滕王宴乐》演出且体力允许，可留到 20:00 后看夜景灯光。  
**自然亮点**：赣江水面 + 红谷滩天际线的江城日落，是这趟旅程唯一的大江景。

## Day 2｜南昌 → 上饶 → 三清山脚（转场日）

| 时间 | 安排 | 说明 |
|------|------|------|
| 09:00–10:30 | 高铁 **南昌西 → 上饶** 或直达 **三清山站** | 沪昆高铁，南昌西→上饶约 1 小时 10 分；部分车次可直接坐到 **三清山站**（原玉山南站），更省一次换乘 |
| 11:30–13:00 | 三清山站 / 上饶站 → 景区服务站 | 打车或景区班车约 50–70 分钟，直达 **金沙（东部）** 或 **外双溪（南部）** 服务站 |
| 下午 | 入住山脚、买票 | 买好次日门票 + 索道票；确认次日索道首班时间（旺季多为 07:30 前后） |
| 傍晚 | 山脚溪边散步、早睡 | 补给水和干粮，山上餐饮贵且选择少 |

**住宿抉择**：  
- **住山脚**（推荐，性价比高）：次日坐首班索道上山，全天在山上。  
- **住山上**（日上山庄 / 女神宾馆等）：条件一般、价格高，但**看日出与云海**不必赶索道，摄影党可考虑。

**提示**：三清山常在雨后放晴时出云海。出发前一晚查天气，若次日为「雨转晴」，反而是最佳窗口。

## Day 3｜三清山：南清园 + 西海岸峰林（江西段最高光）

> 世界自然遗产、世界地质公园。核心看点是**花岗岩峰柱**——极细高的石柱拔地而起，栈道贴着悬崖横切，观感与黄山、张家界都不同。

**推荐环线（一天走完精华）**：  
**外双溪（南部）索道上山 → 南清园 → 西海岸 → 三清宫 → 阳光海岸（东海岸）→ 金沙（东部）索道下山**

反向亦可（金沙上、外双溪下），差别在于：**南部上山**能在上午人少、光线斜射时先拍到巨蟒出山与司春女神。

| 时间 | 路段 | 亮点与说明 |
|------|------|------------|
| 07:30–08:15 | 索道上行 | 索道约 20–25 分钟，上站海拔约 1200–1300 米 |
| 08:30–11:30 | **南清园** | **巨蟒出山**（约 128 米高的独立石柱）、**司春女神**、玉台方向观景；本段台阶最密集，是全天体力大头 |
| 11:30–12:15 | 山上简餐 | 建议自带干粮，节省排队时间 |
| 12:30–15:00 | **西海岸** | 约 3.6 公里高空栈道，**几乎全程平路**，一侧是千米深谷与连绵峰林，云海最常出现在此段 |
| 15:00–16:00 | 三清宫一带 | 古道观 + 古树，人少清静，是山北的收束点 |
| 16:00–17:30 | **阳光海岸**（东海岸） | 同为平缓悬崖栈道，下午顺光，与西海岸互补 |
| 17:30–18:00 | 金沙索道下山 | 留足时间，务必确认末班索道（旺季约 17:00–18:00，淡季更早） |

**最佳游览时间**：  
- **日出**：住山上者去三清宫或玉台方向；  
- **云海**：雨后初晴的清晨概率最高；  
- **杜鹃**：5 月前后高山杜鹃开放，西海岸沿线成片；  
- **避人流**：首班索道上山可领先大部队约 1 小时。

**装备**：防滑徒步鞋（栈道湿滑）、抓绒或薄羽绒（山顶比山下低 6–10℃）、雨衣、2 升水、充电宝。

**降级方案**（体力不足或天气差）：只走 **外双溪上 → 南清园 → 西海岸 → 原路返回**，约 6–7 小时，仍能覆盖八成精华。

## Day 4｜三清山 → 武夷山（转场 + 茶园轻走）

| 时间 | 安排 | 说明 |
|------|------|------|
| 上午 | 下山 / 退房，赴 **三清山站** 或 **上饶站** | 车程约 1 小时 |
| 中午 | 高铁 → **武夷山东站** | 合福高铁在上饶与沪昆交汇，**上饶 → 武夷山东约 1 小时**；部分车次停武夷山北站 / 武夷山站，购票时留意 |
| 14:00–15:00 | 出站 → 武夷山度假区 | 打车约 30–40 分钟（武夷山东站距度假区约 20–30 公里） |
| 15:30–18:00 | **大红袍景区 / 水帘洞** 轻走 | 沿九龙窠茶道慢行，看崖壁上的母树大红袍与两侧茶园，坡度平缓，作为热身刚好 |
| 晚上 | 度假区（三姑）晚餐 | 岚谷熏鹅、文公菜；喝一杯岩茶入门 |

**住宿建议**：住 **度假区（三姑一带）**，步行可达《印象大红袍》剧场，去景区南入口与星村码头都方便。

**购票提醒**：武夷山主景区实行**门票 + 观光车**组合，分一日 / 二日 / 三日票。本行程 D4 傍晚 + D5 + D6 都要进景区，买**二日或三日票更划算**，购票前确认观光车覆盖线路。

## Day 5｜武夷山：天游峰 + 一线天（丹霞主日，不上虎啸岩）

> 武夷山是典型**丹霞地貌**：红色砂砾岩被溪流切割成一座座圆顶石峰，山不高（多在 400 米内）但极陡，观感精巧。  
> 本日按你的要求**舍去虎啸岩**，整体强度从「重」降到「中」，下午多出半天缓冲。

| 时间 | 路线 | 亮点 |
|------|------|------|
| 07:30–08:00 | 景区南入口进，观光车至 **云窝** | 越早越凉快，天游峰是全天最费力的一段 |
| 08:00–10:30 | **天游峰** | 约 800 余级石阶直上，顶部一览亭俯瞰**九曲溪第六曲的大转弯**，被称作武夷第一胜景 |
| 10:30–12:00 | 下山经 **桃源洞 / 茶洞** 成环线 | 峰壁围合的小盆地，安静少人，是天游峰下山最好的一条路 |
| 12:00–13:00 | 午餐 + 换乘 | 回观光车站，转往一线天线路 |
| 13:30–15:00 | **一线天** | 岩缝最窄处仅容侧身通过，抬头只见一线天光；洞内湿滑、有蝙蝠，包别太大 |
| 15:00–16:30 | 顺走 **神仙楼阁 / 楼阁岩** 一带平路 | 一线天出口附近的短环线，看丹霞崖壁与竹林，坡度平缓 |
| 17:00 后 | 返回度假区 | 泡脚、休息，为明天的竹筏与演出留精神 |

**最佳游览时间**：天游峰务必赶早（08:00 前起登，避热避人）；雨后峰顶常见九曲溪谷升腾的水汽，是最出片的状态。  
**若还想加量**：下午有余力可去 **大王峰** 或 **鹰嘴岩 / 流香涧** 的茶园丹霞过渡带，都比虎啸岩轻松。

## Day 6｜武夷山：九曲溪竹筏 + 《印象大红袍》（本趟最惬意的一天）

| 时间 | 安排 | 说明 |
|------|------|------|
| 08:00–10:00 | **九曲溪竹筏漂流** | 从 **星村码头** 顺流而下至 **武夷宫**，约 9.5 公里、1.5–2 小时；六人一筏，两位筏工撑篙讲解 |
| 中午 | 武夷宫 / 宋街午餐 | 竹筏终点即在此 |
| 下午 | 自由：茶馆、**九曲溪畔散步** 或补 **大王峰 / 鹰嘴岩** | 若上午已尽兴，下午纯休息也完全合理 |
| 19:30 或 20:40 | **《印象大红袍》** | 张艺谋团队作品，约 70 分钟，360° 旋转观众席，以真山真水为背景，讲茶与山的故事 |

**竹筏要点**：  
- **必须提前预约**，旺季提前 3–7 天；早班（08:00 前后）水汽未散、光线柔和、最凉快。  
- 沿途依次掠过 **玉女峰、大王峰、晒布岩、小藏峰** 等，抬头就是丹霞峰柱，「人在画中游」说的就是这一段。  
- 防晒帽、薄外套、防水袋（相机可能溅水），穿凉鞋更从容。

**演出选座**：中区中排性价比最好；旋转席位会带你依次面向不同舞台，位置差异没有想象中大，不必追高价区。

## Day 7｜武夷山 → 福州：福建博物院 + 榕城夜色

| 时间 | 安排 | 说明 |
|------|------|------|
| 上午 | 退房，高铁 **武夷山东 → 福州 / 福州南** | 约 1.5–2 小时 |
| 14:00–17:00 | **福建博物院** | 官方名为「福建博物院」，位于 **西湖公园** 内，**免费需预约、周一闭馆**；除历史厅外还有自然馆（恐龙、海洋生物），与本行程的自然主题呼应 |
| 17:00–18:30 | **西湖公园 / 左海** 散步 | 出馆即是园林水系，傍晚榕树与湖面光线极好 |
| 19:00 起 | 三坊七巷 / 上下杭 | 逛外围与巷弄夜色即可；鱼丸、肉燕、荔枝肉、佛跳墙小份 |

**住宿建议**：西湖 / 东街口一带，次日去福州站或福州南站都方便。

**替换方案（更偏自然）**：若你愿意舍掉博物院，可改为 **鼓山半日徒步**（十八景一线，古道石刻 + 俯瞰闽江）。但你明确点名了省博，这里按博物院优先编排。

## Day 8｜福州 → 泉州：清源山 + 洛阳桥日落

| 时间 | 安排 | 说明 |
|------|------|------|
| 08:30–10:00 | 高铁 **福州 → 泉州站** | 约 1–1.5 小时；泉州站距古城约 12 公里，打车 25 分钟 |
| 10:30–11:30 | 入住古城、放行李 | 建议住 **西街 / 中山路** 一带，步行逛城 |
| 12:30–16:00 | **清源山** | 主看 **老君岩**（宋代天然巨石雕成的老子像，树荫溪石环绕）→ **千手岩 / 弥陀岩** → 有余力上 **天湖**；山路平缓好走 |
| 17:30–19:00 | **洛阳桥** | 宋代跨海石桥，桥下是滩涂与红树林，退潮时白鹭成群，日落是全天最佳时刻（记得查当日潮汐与日落时间） |
| 晚上 | 西街、开元寺外围 | 面线糊、姜母鸭、海蛎煎、四果汤 |

**最佳游览时间**：清源山避开正午最晒的两小时；洛阳桥必须傍晚去，逆光滩涂 + 白鹭是泉州最好的自然画面。  
**天气备选**：下雨则改为开元寺 + 泉州海外交通史博物馆，室内为主。

## Day 9｜泉州 → 南靖土楼：云水谣与田螺坑

**交通建议**：这一段公共交通换乘最碎，**包车直达最省事**（泉州 → 南靖书洋镇约 2.5–3 小时）。公共交通方案为：高铁 **泉州 → 南靖站**（约 1.5 小时）→ 站前坐土楼专线 / 打车至书洋镇景区（约 1 小时以上，班车班次少，需提前确认末班）。

| 时间 | 安排 | 说明 |
|------|------|------|
| 上午 | 转场至南靖土楼片区 | 中午前抵达为佳 |
| 13:30–16:30 | **云水谣古道** | 溪流沿村穿过，岸边十几株**千年古榕**冠幅极大，水车、卵石古道；沿线可看 **和贵楼**（沼泽上的方楼）与 **怀远楼** |
| 17:00–18:30 | **田螺坑土楼群** | 观景台俯瞰「四菜一汤」——四圆一方五座土楼嵌在梯田山坳里，傍晚炊烟与斜光最出片 |
| 晚上 | 住土楼客栈 | 云水谣、塔下村或田螺坑附近；夜里安静、星空好 |

**自然向建议**：土楼是人文遗产，但这一段真正的美在**山谷、梯田、竹林与溪水**的组合。少排队钻楼内，多走溪畔与观景台。  
**加分点**：**塔下村**沿溪而建、土楼夹水，被称作「太极水乡」，从云水谣往田螺坑的路上顺路。

## Day 10｜南靖 → 厦门：土楼晨景 + 环岛路看海

| 时间 | 安排 | 说明 |
|------|------|------|
| 06:30–08:00 | **土楼晨雾** | 早起去观景台，山谷晨雾与炊烟是住一晚才能拿到的回报 |
| 09:00–11:00 | 补走昨日未尽的一处 | 田螺坑 ↔ 云水谣 ↔ 塔下，择一深化 |
| 11:30–14:00 | 前往厦门 | 包车约 2–2.5 小时直达岛内；或回南靖站转高铁（需算上到站时间，未必更快） |
| 15:00–16:00 | 入住厦门岛内 | 曾厝垵 / 厦大周边 / 中山路，看海方便 |
| 16:30–19:00 | **环岛路** | 租自行车沿海骑行，**曾厝垵 → 胡里山炮台 → 白城沙滩** 一段最经典，海堤边有木栈道 |
| 晚上 | 沙坡尾 / 曾厝垵 | 海鲜大排档记得先问价 |

**最佳游览时间**：环岛路傍晚 17:00 后风大凉快，日落方向朝西南，演武大桥观景平台是免费好机位。

## Day 11｜厦门：二选一（岛屿 或 海岸线）

建议**只深做一个方案**，两边都赶会很累。

### 方案 A · 鼓浪屿（经典岛屿）
- **07:30–08:30**：从**邮轮中心厦鼓码头**乘船上岛（需**实名预约船票**；轮渡码头的航线主要面向本地居民，游客一般走邮轮中心）
- 岛上：**日光岩**（登顶看海天与厦门岛全景）→ **菽庄花园**（依海построен的园林，听涛轩、四十四桥）→ **皓月园** 海边
- 建议多走 **笔山路、鼓新路** 等安静步道，少钻商业街
- 下午返岛内休息，傍晚看海

### 方案 B · 海岸与山林（自然优先）
- 上午：**万石植物园**（雨林世界的人造喷雾、多肉区、巨石与榕树，海拔起伏小）
- 下午：**山海健康步道**（架空栈道穿林越岭，可俯瞰全城与海湾）或 **五缘湾湿地公园**（水鸟、栈桥）
- 傍晚：**珍珠湾 / 黄厝沙滩** 看日落

晚上：中山路或八市附近收尾。
