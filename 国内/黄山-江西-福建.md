# 黄山 · 江西 · 福建 13 日游（自然风光主题 · 详版）

> **主线**：黄山 → 上饶 / 三清山 → 武夷山 → 福州 → 泉州 → 南靖土楼 → 厦门  
> **自然主轴**：黄山花岗岩奇松云海 → 三清山峰林 → 武夷山丹霞 + 九曲溪 → 清源山 → 土楼山谷梯田 → 厦门海岸  
> **出发地**：深圳。**深圳 → 黄山进，厦门 → 深圳出**，全程单向不走回头路  
> **最佳季节**：4–6 月（黄山云海杜鹃、三清山高山杜鹃、雨后云海）与 9–11 月（天高气爽、秋色通透、闽南最舒适）；7–8 月闽南酷热且台风多，1–2 月山区湿冷（但黄山冬季雾凇雪景另有一绝，代价是天都/莲花常封）  
> **强度**：中等偏上。全程有**两个「大腿日」**——D2 黄山（约 8–10 小时、后山上前山下）与 D4 三清山（约 15–20 公里步行、大量台阶）；D6 武夷山已按需求减去虎啸岩，强度降为中等

> **关于「黄山 + 三清山」**：两座都是花岗岩峰林山岳，观感有重叠。若想换口味、避免连着两天爬同类山，可把 D3–D4 的三清山替换为 **婺源篁岭**（梯田花海 / 晒秋，正好在黄山→上饶的路上）。本版按你的要求**保留三清山**编排，替换方案见文末「弹性调整」。

## Day 1｜深圳 → 黄山：抵达徽州，山脚整备

### 深圳到黄山怎么走

| 方式 | 路线 | 耗时 | 建议 |
|------|------|------|------|
| **高铁（推荐）** | 深圳北 → 黄山北 | 最快约 **4.5–5 小时**，每日约 9 班 | 首班 **06:54**，末班 15:10。选**直达少停站**的早班车，中午前后到黄山北；二等座约 **¥567–646** |
| 飞机 | 深圳宝安 → 黄山屯溪机场 | 飞行约 2 小时 | 航班少、时刻不灵活，除非有合适折扣票，否则高铁更省心 |

**推荐车次（早班直达、下午不浪费）**：
- **G700** 07:21 → 12:09（约 4h48m，仅停 2 站）
- 备选 **G698** 08:35 → 13:41（约 5h6m，直达）
- **避雷**：G3142（12:48→20:59，8 小时多、经停 20 站）这类车次太熬，别选。

### 到了黄山北站怎么去落脚点

黄山「市区（屯溪）」和黄山「风景区（汤口）」是两个地方，第一天先想清楚今晚住哪：

| 落脚方案 | 从黄山北站怎么走 | 适合谁 |
|----------|------------------|--------|
| **汤口镇（山脚·南大门）** | 站前坐**景区直通车 / 旅游专线**约 40–60 分钟（约 70 km），到**汤口换乘中心** | **次日一早爬黄山**的人，首选 |
| 屯溪老街 / 黄山市区 | 打车 / 公交约 15–25 分钟，很近 | 想第一晚逛徽州老街、慢一点的人 |
| 宏村 / 西递 方向 | 站前坐旅游巴士约 1–1.5 小时 | 想先看徽派古村再上山（会多花时间） |

### 当日安排（以中午前后到站为例）

| 时间 | 安排 | 说明 |
|------|------|------|
| 07:00–07:30 | 深圳北出发 | 提前订票选靠窗，赣闽段山景不错 |
| 12:00–13:30 | 抵达黄山北、午餐 | 站内或屯溪解决，别指望山上吃（山上餐饮贵且少） |
| 14:00–15:30 | 转场至 **汤口镇** 入住 | 到换乘中心 / 官方小程序买好次日**门票 + 云谷/玉屏索道票**，确认索道首班时间（旺季多在 06:30–07:00） |
| 16:00–18:00 | 山脚整备 / 或逛 **屯溪老街** | 若住屯溪：老街徽派店铺逛到傍晚；若住汤口：备 1.5–2 升水和干粮、早睡 |
| 晚上 | 徽菜晚餐 | **臭鳜鱼、毛豆腐、徽州圆子、笋干烧肉、石耳炖鸡** |

**住宿抉择**：
- **住汤口**（推荐）：次日坐首班索道 / 早起进山，全天在山上不赶时间。
- **住屯溪老街**：第一晚体验徽州市井，但次日要多花 40–60 分钟才能到山脚，得起更早。

**提示**：黄山雨后初晴最容易出**云海**，出发前一晚查「黄山气象」公众号；若次日「雨转晴」，反而是登山最佳窗口。

## Day 2｜黄山风景区：后山上、前山下（全程不走回头路）

> 世界文化与自然双遗产。核心是**花岗岩奇松 + 怪石 + 云海 + 峡谷**：黄山七十二峰拔地而起，栈道在云雾与绝壁间穿行，「五岳归来不看山，黄山归来不看岳」。

**经典一日环线（八成游客的选择，省力不走回头路）**：  
**汤口换乘中心 → 景区大巴至云谷寺 → 云谷索道上（后山）→ 始信峰 → 北海 → 西海大峡谷 → 光明顶 → 迎客松（玉屏楼）→ 玉屏索道下（前山）→ 慈光阁 → 汤口**

后山（云谷侧）坡缓、奇松最密，适合上山热身；前山（玉屏侧）陡峭险峻、风景雄奇，以下山为主更省力，还能近距离看迎客松。

| 时间 | 路段 | 亮点与说明 |
|------|------|------------|
| 06:30–07:30 | 汤口换乘中心 → 云谷寺 | 越早越好，抢当日前三班大巴（¥19）能领先旅行团约 2 小时的清静 |
| 07:30–08:00 | **云谷索道**上行 | 全程约 2800 米、高差 773 米，约 8–10 分钟，出站即近核心景区（单程约 ¥80） |
| 08:00–10:30 | **始信峰 + 北海景区** | 黑虎松、连理松、竖琴松（奇松最密集区）、梦笔生花、清凉台**猴子观海**；本段相对平缓 |
| 10:30–11:00 | 至 **排云亭** | 西海大峡谷入口，也是黄山看**晚霞**的头号机位 |
| 11:00–14:00 | **西海大峡谷** | 从排云亭往下走一环 / 二环（下坡视野正对深谷，最震撼），到谷底坐**西海大峡谷地轨缆车**返回天海（单程约 ¥100，省下约 4 小时重复爬升） |
| 14:00–15:30 | **光明顶** | 海拔约 1860 米、黄山第二高，视野最开阔，看云海首选；旁有 **飞来石** |
| 15:30–17:00 | 天海 → **鳌鱼峰 → 百步云梯 → 迎客松（玉屏楼）** | 前山精华，台阶陡；迎客松是黄山第一张名片 |
| 17:00–18:00 | **玉屏索道**下山 → 慈光阁 → 大巴回汤口 | 全程约 2176 米、高差 871 米（单程约 ¥90）；**务必确认末班索道 / 末班大巴时间**，别贪景点误了车 |

**最佳游览时间**：
- **日出**：光明顶 / 清凉台 / 曙光亭（需住山上，索道日出前不运行）；
- **日落 / 晚霞**：排云亭、丹霞峰、光明顶；
- **云海**：雨后初晴的清晨概率最高，秋冬也常见；
- **避人流**：首班大巴 + 首班索道，领先大部队约 2 小时。

**装备**：防滑徒步鞋（栈道湿滑）、抓绒或薄冲锋衣（山顶比山下低 6–10℃、风大）、雨衣、1.5–2 升水、干粮、充电宝；看日出加头灯。

**降级方案（省腿 4–6 小时）**：体力有限 / 带老人小孩，走 **慈光阁玉屏索道上 → 迎客松 → 光明顶 → 云谷（白鹅岭）索道下**，全程缆车衔接、避开连续爬升，仍覆盖迎客松 + 光明顶 + 云海精华（代价是错过始信峰与西海大峡谷）。

**升级方案（住山上一晚看日出，整体 +1 天 = 14 天）**：D2 后山上山、慢逛始信峰与西海大峡谷、傍晚在光明顶 / 排云亭看日落，**入住山顶酒店**（白云宾馆 / 光明顶山庄 / 西海饭店，旺季务必提前 2–4 周订、价格翻倍）；次日清晨看日出后再从前山下山、转场三清山。黄山「后山秀美、前山雄奇 + 日出日落云海」的差异感靠这一晚才拿得全。

**注意**：**天都峰、莲花峰实行轮流开放**（一开一封），天都峰想登**须提前单独预约**，现场不预约只能绕行；出行前查官方实时公告。

## Day 3｜黄山 → 上饶 → 三清山脚（转场日）

| 时间 | 安排 | 说明 |
|------|------|------|
| 上午 | 退房，赴 **黄山北站** | 汤口 → 黄山北约 40–60 分钟；预留富余时间 |
| 09:30–11:00 | 高铁 **黄山北 → 上饶**（合福高铁） | 约 1 小时；部分车次可直达 **三清山站**（原玉山南），更省一次换乘 |
| 11:30–13:00 | 上饶 / 三清山站 → 景区服务站 | 打车或景区班车约 50–70 分钟，直达 **金沙（东部）** 或 **外双溪（南部）** 服务站 |
| 下午 | 入住山脚、买票 | 买好次日门票 + 索道票；确认次日索道首班时间（旺季多为 07:30 前后） |
| 傍晚 | 山脚溪边散步、早睡 | 补给水和干粮，山上餐饮贵且选择少 |

**顺路加分（可选）**：黄山 → 上饶途中会经过 **婺源**，若想拆成两段慢走，可在婺源停一晚看 **篁岭**（梯田花海 / 晒秋）与徽派古村，再续程三清山（会多 1 天）。

**住宿抉择**：
- **住山脚**（推荐，性价比高）：次日坐首班索道上山，全天在山上。
- **住山上**（日上山庄 / 女神宾馆等）：条件一般、价格高，但**看日出与云海**不必赶索道，摄影党可考虑。

**提示**：三清山常在雨后放晴时出云海。出发前一晚查天气，若次日为「雨转晴」，反而是最佳窗口。

## Day 4｜三清山：南清园 + 西海岸峰林（江西段最高光）

> 世界自然遗产、世界地质公园。核心看点是**花岗岩峰柱**——极细高的石柱拔地而起，栈道贴着悬崖横切，观感与黄山、张家界都不同。

**推荐环线（一天走完精华）**：  
**外双溪（南部）索道上山 → 南清园 → 西海岸 → 三清宫 → 阳光海岸（东海岸）→ 金沙（东部）索道下山**

反向亦可（金沙上、外双溪下），差别在于：**南部上山**能在上午人少、光线斜射时先拍到巨蟒出山与司春女神。

| 时间 | 路段 | 亮点与说明 |
|------|------|------------|
| 07:30–08:15 | 索道上行 | 索道约 20–25 分钟，上站海拔约 1200–1300 米 |
| 08:30–11:30 | **南清园** | **巨蟒出山**（约 128 米高的独立石柱）、**司春女神**、玉台方向观景；本段台阶最密集，是全天体力大头 |
| 11:30–12:15 | 山上简餐 | 建议自带干粮，节省排队时间 |
| 12:30–15:00 | **西海岸** | 约 3.6 公里高空栈道，**几乎全程平路**，一侧是千米深谷与连绵峰林，云海最常出现在此段 |
| 15:00–16:00 | 三清宫一带 | 古道观 + 古树，人少清静，是山北的收束点 |
| 16:00–17:30 | **阳光海岸**（东海岸） | 同为平缓悬崖栈道，下午顺光，与西海岸互补 |
| 17:30–18:00 | 金沙索道下山 | 留足时间，务必确认末班索道（旺季约 17:00–18:00，淡季更早） |

**最佳游览时间**：
- **日出**：住山上者去三清宫或玉台方向；  
- **云海**：雨后初晴的清晨概率最高；  
- **杜鹃**：5 月前后高山杜鹃开放，西海岸沿线成片；  
- **避人流**：首班索道上山可领先大部队约 1 小时。

**装备**：防滑徒步鞋（栈道湿滑）、抓绒或薄羽绒（山顶比山下低 6–10℃）、雨衣、2 升水、充电宝。

**降级方案**（体力不足或天气差）：只走 **外双溪上 → 南清园 → 西海岸 → 原路返回**，约 6–7 小时，仍能覆盖八成精华。

| 时间 | 安排 | 说明 |
|------|------|------|
| 上午 | 下山 / 退房，赴 **三清山站** 或 **上饶站** | 车程约 1 小时 |

| 14:00–15:00 | 出站 → 武夷山度假区 | 打车约 30–40 分钟（武夷山东站距度假区约 20–30 公里） |

**购票提醒**：武夷山主景区实行**门票 + 观光车**组合，分一日 / 二日 / 三日票。本行程 D5 傍晚 + D6 + D7 都要进景区，买**二日或三日票更划算**，购票前确认观光车覆盖线路。

## Day 6｜武夷山：天游峰 + 一线天（丹霞主日，不上虎啸岩）

> 武夷山是典型**丹霞地貌**：红色砂砾岩被溪流切割成一座座圆顶石峰，山不高（多在 400 米内）但极陡，观感精巧。  
> 本日按你的要求**舍去虎啸岩**，整体强度从「重」降到「中」，下午多出半天缓冲。

| 时间 | 路线 | 亮点 |
|------|------|------|
| 07:30–08:00 | 景区南入口进，观光车至 **云窝** | 越早越凉快，天游峰是全天最费力的一段 |
| 08:00–10:30 | **天游峰** | 约 800 余级石阶直上，顶部一览亭俯瞰**九曲溪第六曲的大转弯**，被称作武夷第一胜景 |
| 10:30–12:00 | 下山经 **桃源洞 / 茶洞** 成环线 | 峰壁围合的小盆地，安静少人，是天游峰下山最好的一条路 |
| 12:00–13:00 | 午餐 + 换乘 | 回观光车站，转往一线天线路 |
| 13:30–15:00 | **一线天** | 岩缝最窄处仅容侧身通过，抬头只见一线天光；洞内湿滑、有蝙蝠，包别太大 |
| 15:00–16:30 | 顺走 **神仙楼阁 / 楼阁岩** 一带平路 | 一线天出口附近的短环线，看丹霞崖壁与竹林，坡度平缓 |
| 17:00 后 | 返回度假区 | 泡脚、休息，为明天的竹筏与演出留精神 |

**最佳游览时间**：天游峰务必赶早（08:00 前起登，避热避人）；雨后峰顶常见九曲溪谷升腾的水汽，是最出片的状态。  
**若还想加量**：下午有余力可去 **大王峰** 或 **鹰嘴岩 / 流香涧** 的茶园丹霞过渡带，都比虎啸岩轻松。

## Day 7｜武夷山：九曲溪竹筏 + 《印象大红袍》（本趟最惬意的一天）

| 时间 | 安排 | 说明 |
|------|------|------|
| 08:00–10:00 | **九曲溪竹筏漂流** | 从 **星村码头** 顺流而下至 **武夷宫**，约 9.5 公里、1.5–2 小时；六人一筏，两位筏工撑篙讲解 |
| 中午 | 武夷宫 / 宋街午餐 | 竹筏终点即在此 |
| 下午 | 自由：茶馆、**九曲溪畔散步** 或补 **大王峰 / 鹰嘴岩** | 若上午已尽兴，下午纯休息也完全合理 |
| 19:30 或 20:40 | **《印象大红袍》** | 张艺谋团队作品，约 70 分钟，360° 旋转观众席，以真山真水为背景，讲茶与山的故事 |

**竹筏要点**：
- **必须提前预约**，旺季提前 3–7 天；早班（08:00 前后）水汽未散、光线柔和、最凉快。  
- 沿途依次掠过 **玉女峰、大王峰、晒布岩、小藏峰** 等，抬头就是丹霞峰柱，「人在画中游」说的就是这一段。  
- 防晒帽、薄外套、防水袋（相机可能溅水），穿凉鞋更从容。

**演出选座**：中区中排性价比最好；旋转席位会带你依次面向不同舞台，位置差异没有想象中大，不必追高价区。

## Day 8｜武夷山 → 福州：福建博物院 + 榕城夜色

| 时间 | 安排 | 说明 |
|------|------|------|
| 上午 | 退房，高铁 **武夷山东 → 福州 / 福州南** | 约 1.5–2 小时 |
| 14:00–17:00 | **福建博物院** | 官方名为「福建博物院」，位于 **西湖公园** 内，**免费需预约、周一闭馆**；除历史厅外还有自然馆（恐龙、海洋生物），与本行程的自然主题呼应 |
| 17:00–18:30 | **西湖公园 / 左海** 散步 | 出馆即是园林水系，傍晚榕树与湖面光线极好 |

## Day 9｜福州 → 泉州：清源山 + 洛阳桥日落

| 时间 | 安排 | 说明 |
|------|------|------|
| 08:30–10:00 | 高铁 **福州 → 泉州站** | 约 1–1.5 小时；泉州站距古城约 12 公里，打车 25 分钟 |
| 10:30–11:30 | 入住古城、放行李 | 建议住 **西街 / 中山路** 一带，步行逛城 |
| 12:30–16:00 | **清源山** | 主看 **老君岩**（宋代天然巨石雕成的老子像，树荫溪石环绕）→ **千手岩 / 弥陀岩** → 有余力上 **天湖**；山路平缓好走 |
| 17:30–19:00 | **洛阳桥** | 宋代跨海石桥，桥下是滩涂与红树林，退潮时白鹭成群，日落是全天最佳时刻（记得查当日潮汐与日落时间） |
| 晚上 | 西街、开元寺外围 | 面线糊、姜母鸭、海蛎煎、四果汤 |

**最佳游览时间**：清源山避开正午最晒的两小时；洛阳桥必须傍晚去，逆光滩涂 + 白鹭是泉州最好的自然画面。  
**天气备选**：下雨则改为开元寺 + 泉州海外交通史博物馆，室内为主。

## Day 10｜泉州 → 南靖土楼：云水谣与田螺坑

**交通建议**：这一段公共交通换乘最碎，**包车直达最省事**（泉州 → 南靖书洋镇约 2.5–3 小时）。公共交通方案为：高铁 **泉州 → 南靖站**（约 1.5 小时）→ 站前坐土楼专线 / 打车至书洋镇景区（约 1 小时以上，班车班次少，需提前确认末班）。

| 时间 | 安排 | 说明 |
|------|------|------|
| 上午 | 转场至南靖土楼片区 | 中午前抵达为佳 |
| 13:30–16:30 | **云水谣古道** | 溪流沿村穿过，岸边十几株**千年古榕**冠幅极大，水车、卵石古道；沿线可看 **和贵楼**（沼泽上的方楼）与 **怀远楼** |
| 17:00–18:30 | **田螺坑土楼群** | 观景台俯瞰「四菜一汤」——四圆一方五座土楼嵌在梯田山坳里，傍晚炊烟与斜光最出片 |
| 晚上 | 住土楼客栈 | 云水谣、塔下村或田螺坑附近；夜里安静、星空好 |

**自然向建议**：土楼是人文遗产，但这一段真正的美在**山谷、梯田、竹林与溪水**的组合。少排队钻楼内，多走溪畔与观景台。  
**加分点**：**塔下村**沿溪而建、土楼夹水，被称作「太极水乡」，从云水谣往田螺坑的路上顺路。

| 时间 | 安排 | 说明 |
|------|------|------|
| 06:30–08:00 | **土楼晨雾** | 早起去观景台，山谷晨雾与炊烟是住一晚才能拿到的回报 |
| 09:00–11:00 | 补走昨日未尽的一处 | 田螺坑 ↔ 云水谣 ↔ 塔下，择一深化 |

## Day 12｜厦门：二选一（岛屿 或 海岸线）

建议**只深做一个方案**，两边都赶会很累。

### 方案 A · 鼓浪屿（经典岛屿）
- **07:30–08:30**：从**邮轮中心厦鼓码头**乘船上岛（需**实名预约船票**；轮渡码头的航线主要面向本地居民，游客一般走邮轮中心）
- 岛上：**日光岩**（登顶看海天与厦门岛全景）→ **菽庄花园**（依海而建的园林，听涛轩、四十四桥）→ **皓月园** 海边
- 建议多走 **笔山路、鼓新路** 等安静步道，少钻商业街
- 下午返岛内休息，傍晚看海

### 方案 B · 海岸与山林（自然优先）
- 上午：**万石植物园**（雨林世界的人造喷雾、多肉区、巨石与榕树，海拔起伏小）
- 下午：**山海健康步道**（架空栈道穿林越岭，可俯瞰全城与海湾）或 **五缘湾湿地公园**（水鸟、栈桥）
- 傍晚：**珍珠湾 / 黄厝沙滩** 看日落

晚上：中山路或八市附近收尾。
