# 黄山 · 景德镇 · 江西 · 福建 15 日游（博物馆 + 自然风光 · 高铁 · 经济型）

> **主线**：深圳 → 黄山 → 景德镇 → 南昌 → 三清山 → 武夷山 → 福州 → 泉州 → 厦门 → 深圳  
> **主题**：**博物馆人文**（陶瓷、赣鄱、海丝）+ **自然山水**（黄山、三清山、武夷山、闽南海岸）  
> **出发地**：深圳。**深圳 → 黄山进，厦门 → 深圳出**，全程单向不走回头路  
> **三大原则（按你的要求）**：
> - **交通**：城市之间**全程高铁**（昌景黄 + 沪昆 + 合福 + 厦深贯通，衔接顺）
> - **爬山**：**能索道就索道**（黄山双索道 + 西海地轨、三清山索道），尽量少爬台阶
> - **住宿**：**经济连锁酒店 / 高性价比民宿**（汉庭、如家、锦江之星、7 天、尚客优等，人均预算友好）
> **最佳季节**：4–6 月、9–11 月（山区通透、闽南舒适）；7–8 月闽南酷热多台风，1–2 月山区湿冷  
> **强度**：中等。山岳几乎全靠索道代步；唯一较费力的是武夷山**天游峰**（无索道、约 800 级台阶），可按体力选择跳过。

## Day 2｜黄山风景区：双索道登山（尽量少爬）

> 世界文化与自然双遗产。核心是**奇松 + 怪石 + 云海 + 峡谷**。按「多用索道」的原则，走**后山上、前山下**经典线，两头都坐索道，中间尽量走平缓段。

**推荐环线**：汤口换乘中心 → 大巴至云谷寺 → **云谷索道上** → 始信峰 / 北海 → 西海大峡谷（下行 + **地轨缆车**返程）→ 光明顶 → 迎客松（玉屏楼）→ **玉屏索道下** → 慈光阁 → 汤口。

| 时间 | 路段 | 说明 |
|------|------|------|
| 06:30–07:30 | 汤口 → 云谷寺（大巴 ¥19） | 抢前三班车领先旅行团约 2 小时 |
| 07:30–08:00 | **云谷索道**上（单程约 ¥80） | 约 8–10 分钟，出站即近核心区 |
| 08:00–10:30 | 始信峰 / 北海 | 奇松最密（黑虎松、连理松）、猴子观海 |
| 11:00–14:00 | **西海大峡谷** | 从排云亭下行看深谷，谷底坐**西海地轨缆车**（单程约 ¥100）返天海，省 4 小时爬升 |
| 14:00–15:30 | **光明顶**（1860 m） | 视野最开阔、看云海；旁有飞来石 |
| 15:30–17:00 | 鳌鱼峰 → 百步云梯 → **迎客松** | 前山精华，台阶陡但以下山为主 |
| 17:00 后 | **玉屏索道**下（单程约 ¥90）→ 慈光阁 → 回汤口 | **务必确认末班索道 / 末班大巴** |

**最省腿版（4–6 小时，几乎不爬）**：慈光阁 **玉屏索道上 → 迎客松 → 光明顶 → 云谷（白鹅岭）索道下**，全程缆车衔接、避开连续爬升（代价是略过始信峰与西海大峡谷）。适合只想轻松打卡迎客松 + 光明顶云海。

**注意**：天都峰、莲花峰轮流开放，天都峰想登须**单独预约**；本行程按索道优先，默认不登天都峰。

## Day 7｜三清山：索道 + 平路栈道（南清园 + 西海岸）

## Day 13｜泉州（周三）：清源山 + 古城 + 泉州博物馆 + 洛阳桥

> 昨天博物院占了上午，**清源山移到今天一早**（也更凉快）；古城宗教古建顺路穿插。

| 时间 | 安排 | 说明 |

| 11:00–12:30 | **开元寺**（东西塔）+ **西街** | 千年古街；顺路可看涂门街的清净寺 / 关岳庙 / 天后宫（宋元多元宗教古建密集区） |
